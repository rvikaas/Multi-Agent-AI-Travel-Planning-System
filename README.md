An AI Travel Planning System that uses 4 specialized AI agents:
✈️ Flight Agent
🏨 Hotel Agent
🗓️ Itinerary Agent
🤖 Final Response Agent

Each AI agent performs its own task, and together they work as one intelligent system.

In this project, we will:
✅ Build a Multi-Agent AI Application using LangGraph
✅ Use Llama 3.3 70B with Groq
✅ Add Memory using PostgreSQL
✅ Fetch Real-time Flight Data using AviationStack API
✅ Search Hotels using Tavily Search API
✅ Create a complete AI Travel Planner
✅ Learn Agentic AI Architecture Step by Step

Tech Stack Used:
LangGraph
Groq
Llama 3.3 70B
PostgreSQL
Tavily Search API
AviationStack API
Streamlit
